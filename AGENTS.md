## Agent skills

### Issue tracker

Issues and PRDs are tracked in GitHub Issues; external contributor PRs are also a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The canonical default triage labels are used. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context layout. See `docs/agents/domain.md`.

### Database operations

Use the Neon MCP server for database work rather than a script wired to `DATABASE_URL`.
