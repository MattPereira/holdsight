# Holdsight

## Access

Holdsight is a closed instance. Set `ALLOWED_EMAILS` to a comma-separated list
of approved Google account email addresses. Matching is case-insensitive. The
application refuses to start when the list is missing or empty.

```dotenv
ALLOWED_EMAILS=matt@example.com,partner@example.com
```

## Portfolio
- Connect a wide variety of traditional finance and crypto platforms
- View balances for each asset and account along with overall portoflio allocations
- Formulate and track investment theses and allocation strategies

## Journal
- Attatch a journal entry to each individual trade
- Manage general planning and reflections for each day, week, and month
